# Part 2 · 表情驱动的直播 AR 互动原型

在线测试：[打开直播 AR 演示](https://lana-rain.github.io/part2-expression-ar-demo/)（允许浏览器使用摄像头，无需安装）。

下载源码：[获取项目 ZIP](https://github.com/lana-rain/part2-expression-ar-demo/archive/refs/heads/main.zip)。

这是一个在浏览器里运行的 TikTok LIVE 风格**独立原型**，不是 TikTok 官方产品，也不接入真实直播流、账号、礼物支付或金币。打开网页并授权摄像头后，默认的自然互动模式中，主播微笑会持续下雨；确认开口大笑，或有足够面部证据的捂嘴大笑，会持续播放预制烟花。表情稳定回到平静时特效渐隐；微笑和大笑可以直接切换，无须先恢复无表情。较亮的烟花火星会在跟随头部移动的二维近似边界折返，产生局部二次碎花。实验台还可切换礼物后短窗、手动 PK 阶段和手动话题片段，用来比较玩法何时开放更合适；这些是产品假设，不是原始需求指定的入口。

仓库结构：`app/` 是网页源码与测试，`docs/` 是需求拆解、验证说明及 [Part 2 PDF 介绍](docs/part2-requirement-decomposition-and-retrospective.pdf)。更详细的运行方式见 [app/README.md](app/README.md)。

历史验证截图可能包含真人摄像头画面，因此只留在原开发机，不随这个公开源码包发布。仓库内的图像模拟素材为生成样本，供本地复现识别边界；公开网页构建会自动剔除它们。

## 在线体验

直接打开[在线演示](https://lana-rain.github.io/part2-expression-ar-demo/)即可测试。仓库使用 GitHub Actions 自动运行测试、构建并发布到 GitHub Pages。

1. 用支持摄像头的桌面或移动浏览器打开 HTTPS 页面，并允许使用摄像头。页面只请求视频，不请求麦克风。
2. 闭嘴、嘴角上扬：观察顶部云聚拢、雨淋到发顶及镜头水滴。
3. 张嘴时仍有明显笑意且双眼参与：观察烟花升空、持续绽放和头缘火星折返。
4. 恢复平静：观察特效收束。普通说话、单纯眯眼或普通捂嘴不应被当作大笑。

公开网页只提供**实时摄像头体验**。镜头画面在浏览器本地参与识别和绘制；项目不录音、不连接真实直播服务。PK 与话题片段仅由实验台手动模拟，不接真实平台事件，也不自动理解主播讲话。第一次授权、换浏览器或清除站点权限后，浏览器可能要求重新允许摄像头。摄像头网页需要 HTTPS，或在本机使用 `localhost`。

## 本地开发与验证

需要 Node.js 22 或 24、pnpm 11。`app/` 是 Vite 项目根目录，依赖版本由 `app/pnpm-lock.yaml` 固定：

```sh
cd app
pnpm install --frozen-lockfile
pnpm dev
```

打开 `http://localhost:5173/`。本地开发模式保留“互动实验台”的图像模拟输入，用中性、微笑、大笑、只张嘴等固定样本检查识别、状态转换和特效。它们经过与摄像头相同的识别及渲染链路，但**静态图、合成视频和自动化测试不能替代真人摄像头验收**。

随后仍在 `app/` 目录执行：

```sh
pnpm test
pnpm build
pnpm preview
```

`pnpm build` 生成供 GitHub Pages 发布的摄像头版 `app/dist/`，不发布开发用的图像验证入口及素材。项目使用相对资源路径，支持 GitHub Pages 的 `/仓库名/` 子路径。`dist/` 是构建产物，不需要手动提交到仓库；工作流会从 `app/` 源码重新构建并发布。

## 实现边界

- 人脸与手部关键点在浏览器中提供动作代理信号。微笑、大笑是本原型的**动作规则**，不是对情绪或笑声的医学/心理判断。
- 雨云、雨滴、烟花形态和配色预先设计；运行时选择效果、更新位置、节奏与粒子轨迹，不实时生成图像。
- 头部碰撞采用屏幕空间二维近似，不等于精确头发分割或三维物理模拟。
- 真人不同脸型与光照、快速头动、实体手机摄像头和长期性能仍需进一步验收。

人脸/手部识别采用 [MediaPipe Tasks Vision](https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker)，模型与 WASM 静态资源随网页提供。礼物数值、主播身份和观众数据均为演示内容。
